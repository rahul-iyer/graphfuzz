# Grammars

- `gql/GQL.g4`: OpenGQL's ANTLR 4 grammar for ISO/IEC 39075:2024 (GQL), copied from DuckGQL's
  `third_party/opengql/GQL.g4`; upstream is https://github.com/opengql/grammar. Apache License 2.0.
- `opencypher/Cypher.g4`: the openCypher 9 grammar, milestone M23, from
  https://s3.amazonaws.com/artifacts.opencypher.org/M23/Cypher.g4. Apache License 2.0.
